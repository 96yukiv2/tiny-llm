# モデルの構造

1. `tokenizer.py` は学習テキスト中の Unicode 文字を並べ、各文字に ID を割り当てます。日本語を単語に分割せず扱えますが、系列が長くなるという制約があります。
2. `dataset.py` は連続する文字列を切り出し、入力を一文字ずらしたものを正解にします。例えば `日本語` に対し、入力 `日本` の正解は `本語` です。
3. `model.py` は文字と位置の埋め込みを足し、Transformer のブロックを通します。自己注意の三角マスクは、各位置が未来の文字を見られないようにします。各ブロックには残差接続、層正規化、フィードフォワード層があります。
4. `train.py` は次の文字の予測と正解のクロスエントロピーを計算し、AdamW で重みを更新します。評価時は重みを更新せず、ドロップアウトを無効にします。
5. `generate.py` は直近 `block_size` 文字から次の文字の確率を求め、サンプリングを繰り返します。温度を下げると確率の高い文字を選びやすくなります。

チェックポイントにはモデル設定、重み、文字の対応表を保存します。生成時は `weights_only=True` で読み込みます。計算を追いやすくするため、分散学習などは含めていません。
